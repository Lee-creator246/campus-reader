## 本地 APK 与源码包核验

- Release APK 使用通用项目证书签名，v1、v2、v3 签名验证通过，调试标志为 `false`。私有签名密钥库不进入公开仓库或源码包。
- 最终 Manifest 包含配置、规则预览、提醒记录、AI 设置、摘要和非导出的门户登录入口，以及非导出的 `ConsentStorageProvider`；原始厂商 `HSProvider` 不存在。
- 对 DEX 字符串、Android 资源字符串、原生库可打印字符串、文本资源及解码后的 Manifest 扫描，已知学校、个人和开发环境标记命中为 0；未发现私有签名文件或运行时数据库。此结果是已知模式检查，不是对任意秘密或第三方组件的完整安全证明。
- 校园配置和 AI 服务默认为空；AI 默认关闭。Release 禁用构建系统写入 Git 版本控制元数据。
- 学校目录、门户凭据和登录会话不进入安装包。公开源码只含示例学校数据；用户导入的目录保存在不参与备份的应用私有目录。门户固定密码加密保存，动态密码不保存。
- `scripts/check_public_tree.py` 检查公开文件白名单及已知秘密模式；`scripts/package_source.py` 生成带逐文件 SHA-256 清单的 ZIP，并验证 ZIP 完整性及每个文件哈希。源码包排除 SDK、APK、本机配置、签名密钥和应用缓存。
- APK 仍含专有校园连接 SDK，其再分发许可尚未确认。本轮生成本地安装包，没有上传二进制 GitHub Release；MIT 授权仅覆盖本项目代码及声明适用的部分。

## 尚需单独验证的行为

独立安全审查的源码范围、加固和未完成门槛见 [安全审查说明](SECURITY_REVIEW.md)。本版不能表述为“完整安全审计通过”。

- 真实设备上的校园动态码、门户 SSO、SDK IPC、账号切换和内容访问；本轮没有连接手机。
- 首次保存后认证、SDK 启动后改配置并重新打开、Provider 延迟初始化及配置变更后的 Cookie 清除。
- 厂商电池管理、后台任务时机、系统通知横幅与声音，以及不同 Android 版本的实际权限行为。
- AndroidKeyStore 的真机密钥生命周期、设备升级、恢复和失效处理；主机替代实现不能证明设备行为。
- 保存固定密码后门户自动恢复、验证码/锁定/错误密码处理、30 秒恢复超时、退出和系统杀进程的完整行为。自动恢复只适用于已识别且目标匹配的认证表单，不保证所有学校可自动登录。
- 真实 AI 服务对指定模型、JSON 输出格式和令牌参数的兼容性，摘要事实准确率、费用、延迟和隐私政策。引用存在检查不能证明模型概括在语义上正确。
- 改换站点后的页面、分页和附件适配。运行时地址可配置不等于任意门户结构均受支持。
- 目标 SDK 迁移、专有原生库兼容性和应用商店要求；当前本地 APK 不代表应用商店审核通过。
- GitHub Actions 是否运行成功应以对应远程记录为准。
