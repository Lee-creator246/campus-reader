# 第 7 版原生界面

本轮参考 Hallmark 的应用界面原则，保留 Android 原生导航、通知列表、阅读器和设置功能。采用项目现有蓝色方向，不引入营销页结构、装饰照片或新的数据展示。

## 设计决定

- 主文字、次文字、背景、分隔线、选中态和危险操作使用集中颜色定义。Java 为 `ReaderUi`，XML 为 `colors.xml`；两者值保持一致。
- 通知标题是列表的主要信息。正文标题 18 sp，来源和日期 13 sp，已读与未读仍用字重和颜色区分，稍后读保留书签标记。
- 图片卡片采用图片在上、文字在下的白底结构。标题不叠在照片上，也不受固定卡片高度裁剪。无图内容继续使用纯文字行。
- 阅读底栏保留已读、摘要、稍后读、标签和更多入口，每个操作具有至少 48 dp 的点击区域。控件高度随放大后的文字和图标增长。
- 设置分类增加简短说明，行高由内容决定。打开时刷新和门户恢复位于“打开 App 时”，后台刷新与系统权限分别成组；危险清理操作仍需确认。
- 可操作行提供即时焦点边框和按下反馈；保留系统辅助功能语义及原有内容描述。界面不新增装饰动画。

## 验证边界

Hallmark 的网页扫描器只识别 HTML、CSS 及网页框架文件。对本项目的 Android XML 布局执行扫描时，工具返回没有支持的文件；这不是检查通过，也不能用于证明原生 Android 界面合格。

`ReaderLayoutTest` 使用 Robolectric API 28 的原生图形模式，检查 320 dp 宽、1.3 倍字体下的图片卡片、五个阅读操作和设置行，成功时输出到构建目录的 `verification/ui-v7/`。图片使用合成内容，属于原生布局的主机渲染，不能标注为手机截图。实际运行结果以本版验证记录为准。

仍需在手机上检查系统字体、键盘遮挡、TalkBack、系统栏、安全区域、不同厂商控件和真实长通知。主机图片不覆盖这些设备行为。

参考：[Hallmark](https://github.com/Nutlope/hallmark)。设计原则经过原生界面适配；本项目不复制其网页主题资源或商业阅读器界面资产。
