# 校园阅读 · Campus Reader

面向校园信息门户的 Android 本地通知阅读器。配置站点并完成校园连接和门户登录后，将通知缓存到手机，支持已读、稍后读、标签、关键词屏蔽和优先提醒。

这是独立开源项目，不代表任何学校或服务提供商。当前应用版本为 **0.6.0-campus**，仍处于验证阶段。本版增加配置导入、规则预览与撤销、提醒记录和可选的手动 AI 摘要。

## 功能

- 首次打开不预填或连接任何校园站点；在“校园配置”手填、粘贴或导入配置文件，核对差异并同意连接服务说明后，再建立校园通道、单独完成门户登录。
- 校园通道与门户登录分开显示下一步操作；只有实际解析门户响应成功，才确认门户可用。可查看最近完整刷新成功时间。
- 抓取通知标题、发布时间、正文、原文地址、图片和附件入口；按发布时间倒序排列，按稳定门户编号去重。
- 已读 / 未读、稍后读、标签独立管理；重复刷新保留阅读状态，登录过期保留本地内容。
- 支持列表、杂志、图片卡片视图；没有图片时使用纯文字行。
- 搜索标题和缓存正文，支持组合筛选；侧栏“关键词规则”设置屏蔽词和优先提醒词，“重点关注”查看匹配内容。
- 屏蔽词优先于提醒词；规则按站点配置和账号隔离保存，清空搜索不会清空规则，屏蔽不会删除阅读状态或标签。
- 保存前可预览规则命中，查看已屏蔽内容，暂停规则或撤销上一次保存；预览不会联网、标记已读或发送提醒。
- 后台定时刷新、通知渠道、缓存条数与容量设置；默认已读超过 24 小时可清正文，保留轻量历史和状态。
- “刷新与提醒记录”保留当前账号最近 14 天、最多 200 条诊断记录，解释为什么提醒或未提醒；“已提交系统”不等于用户已看到。
- 图片查看及保存、附件下载与导出，本地 RSS / Atom 订阅。
- 单篇通知可手动生成 AI 摘要，提取事项、对象、行动、时间和地点，并查看原文依据；摘要缓存后可离线查看，正文变化或清理时同步失效。

关键词只匹配标题及仍缓存的正文，不识别图片中的文字。优先提醒随后台刷新触发，受认证状态、电池管理和系统通知权限影响；新增规则不会重推所有历史通知。

## 可选 AI 摘要

AI 默认关闭，安装包不附服务地址、模型、API Key 或免费额度。在侧栏的 AI 设置中填写自己有权使用的 HTTPS 服务地址、模型与密钥；服务须兼容 `chat/completions` 和 `response_format: {"type":"json_object"}`。启用后，在通知中点击“AI 摘要”，每次先核对服务方和将发送的完整标题、文字正文，再确认发送。

首版只分析已缓存文字，不识别图片或附件。每次最多发送 12,000 个字符，输出上限 1,000 tokens；每个本地账号每天最多尝试 20 次，失败、超时和取消也占用次数，不自动重试。API 费用、服务端数据留存与删除按用户选择的服务方规则处理。摘要引用校验只能确认引文存在，不能保证模型的解释正确；时间和报名要求请核对原文。

AI 不改变已读、稍后读或标签，也不参与关键词规则。关闭 AI 后仍可查看已有摘要；设置中可单独删除密钥或清空摘要。本版未进行真实 AI 服务调用或手机调试，具体检查与未验证范围见 [验证记录](docs/VALIDATION.md)。

## 获取与构建

需要 JDK 17、Android SDK 36 和 Build Tools 36.0.0。完整 App 还需要自行取得有权使用的 **SangforSDK.aar**；仓库不提供该专有二进制，也不会自动下载它。

```sh
# 无需厂商 SDK，执行合成数据核心测试
./gradlew :checks:verify

# 配置 Android SDK 后，使用自己持有的 SDK 构建
./gradlew :app:assembleDebug :app:lintDebug -PsangforSdk=/absolute/path/SangforSDK.aar
```

Windows 使用 `gradlew.bat`。站点参数在安装后的“校园配置”页面填写，无需修改源码或重新构建。首次保存即可继续校园认证和门户登录；连接 SDK 已启动后修改配置，需选择“保存并关闭应用”再从桌面打开。完整步骤及已知平台限制见 [BUILDING.md](BUILDING.md)。

当前解析器适配特定的门户页面结构，认证适配也依赖特定 SDK；修改地址不意味着自动兼容所有学校，需要根据目标系统验证或调整适配代码。

## 项目结构

| 模块 | 职责 |
| --- | --- |
| `campus-config` | 校验运行时站点参数、限制网址范围、生成站点隔离标识；默认未配置 |
| `app` | 阅读界面、规则预览、提醒记录、手动 AI 请求与密钥设置、后台任务、RSS、图片和附件 |
| `campus-auth` | 官方 SDK 适配、账号认证、隧道状态与生命周期 |
| `campus-extension` | SQLite 缓存、稳定身份、阅读状态、标签、摘要及内容版本、缓存清理 |
| `campus-portal` | 门户列表、正文、附件和分页解析 |
| `checks` | 无需账号、网络抓取或专有 SDK 的 JVM 回归测试 |

架构与认证边界见 [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)，验证范围见 [docs/VALIDATION.md](docs/VALIDATION.md)。

## 公开内容与本机配置

界面使用项目自有布局、几何图标和标准 Android 控件。仓库只发布源代码、构建配置及合成测试，不包含真实站点配置、校园通知样本、用户数据、登录凭据、签名私钥、设备转储或商业 SDK。第三方依赖说明见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

应用包不预置站点、账号或登录票据。用户填写的服务地址与连接服务同意状态仅保存到应用私有存储；配置网址不得夹带密码、验证码、Cookie 或登录票据。配置文件不承载账号、登录会话、阅读历史或 AI 密钥，导入不会自动表示同意连接服务。旧版 `campus.local.properties` 仍被忽略，但构建不再读取。合成测试各自显式安装测试配置，生产默认值保持为空。

修改配置会退出校园连接并清除门户 Cookie、网页存储和客户端证书选择；缓存、标签和规则按站点配置及账号隔离保留。同一个账号在不同配置下不会共享通知、图片或附件缓存。

## 使用与贡献

1. 安装后进入“校园配置”，手填或导入校园认证域、VPN HTTPS 入口、门户通知列表地址及可选的门户登录地址。导入格式见 [构建与配置说明](BUILDING.md)。
2. 阅读并同意连接服务说明，保存后输入校园账号与动态密码，再单独完成门户登录。
3. 刷新通知；需要重新登录时按 App 提示操作。
4. 在侧栏管理稍后读、标签、关键词规则；查看刷新与提醒记录，按需配置 AI。
