# 北邮人信息 · Campus Reader

北邮人信息是北京邮电大学信息门户的本地通知阅读器。Android 版 **0.9.1-campus（versionCode 15）** 支持校园登录、偏好推荐、通知提醒和带原文引用的 AI 摘要。iOS 验证版以同一版本的门户行为为基准，使用 SwiftUI 和独立的本机存储。项目独立维护。iOS 的构建、分发与实测步骤见 [iOS 工程说明](ios/README.md)。

## 使用

1. 首次打开进入原生门户登录页，输入学工号与门户密码，可选择本机保存并自动恢复。校内优先检测直连，网络不可达时再进入 VPN 认证；门户登录过期不等同于需要重连 VPN。
2. 首次登录后可选择关注主题、关注词和屏蔽词，也可跳过。适用对象选填，偏好按账号保存在本机，之后可在侧栏修改。
3. 首页切换“为你推荐”“最新”“未读”“稍后读”，顶部选择主题标签。“最新”按发布时间倒序；长按打开预览，不自动标为已读，打开正文才标记。
4. 如需 AI，在设置中配置自己的 DeepSeek 或兼容服务与 API Key。选择“保存并开启自动摘要”后，当前页及新增通知进入有界任务队列；自动发送政策片段需要另行勾选。

## 主要能力

- 获取通知标题、发布时间、正文、图片、原文地址及附件入口，按稳定门户编号去重；没有图片时显示文字行。
- 已读、稍后读和个人标签互相独立，刷新和认证失效保留本地状态；保留 RSS / Atom 订阅、图片查看与附件导出。
- 本机内容推荐优先使用主动选择的主题和关键词，可显示推荐原因。“多推荐此类 / 不感兴趣”形成有界、衰减的本机权重；已读和未读不作为喜好，学习可关闭、重置。
- 硬屏蔽优先于关注、推荐和提醒；可查看屏蔽结果、预览规则命中、撤销上次规则保存。关键词只匹配标题和仍缓存的正文，不识别图片文字。
- 后台默认每 30 分钟择机检查，可选 15 分钟等间隔；进程存活期间的网络恢复会合并安排一次补查。普通通知合并展示，明确关注词或启用提醒的主题可进入重点渠道，学习分数不自行升级响铃。
- 提醒按当前账号、稳定通知身份和最新规则校验。首次同步不批量提醒历史内容，重复发布回调有本机投递去重；单条提醒支持稍后读、标为已读。
- Android 7.0 / API 24 及以上可将已有摘要静默补入仍活跃的同一条通知，最多展示四条；取消、换账号、正文变更或新聚合替换后不补发旧通知。API 23 保留初始通知，不执行此静默更新。
- 用户可手动为某条通知选择提醒时间，使用系统非精确闹钟；开机后恢复登记。应用不凭 AI 推测的时间直接创建提醒。
- 正文默认最多 300 条 / 20 MiB，图片缓存默认 40 MiB；已读超过 24 小时可清正文，保留标题、阅读状态和标签。稍后读、带标签正文优先保留，仍受容量上限约束。
- “刷新与提醒记录”保存当前账号最近 14 天、最多 200 条本机诊断。“已提交系统”不表示已经被用户看到。
- “体验反馈”提供自愿问卷，仅在本机填写，预览后自行通过系统分享；没有自动上传、问卷接收服务器或隐式使用统计。

系统通知权限、休眠、厂商电池管理、网络及门户会话都会影响提醒。后台锁定、自启动等需用户在系统中设置，不承诺进程永不被回收或实时送达；门户过期时，打开 App 进行前台恢复，验证码及 VPN 动态密码由用户完成。

## AI 摘要与依据

AI 初始关闭，安装包没有密钥或免费额度。DeepSeek 预设使用官方 HTTPS 接口并明确关闭思考，自定义服务需支持兼容的 `chat/completions` 与 JSON 输出。更换接口不能静默沿用旧密钥或自动发送授权。

新摘要采用 schema 3：简短概述、有限行动要点及对应原文短引文。列表展示摘要，长按和正文顶部显示完整卡片；句末右上角数字可打开来源、位置及上下文，政策参考默认折叠。模型可以压缩表述，App 检查来源、部分数字 / 日期 / 单位和否定词；未通过的表述可能回退原文摘录。**这些检查不能证明语义正确、资格适用或条件完整。**

自动与手动请求共享每账号每日尝试上限，默认 20 次，可在 1—100 次范围调整，失败或取消也计入。当前页每次最多入队 10 篇，新增通知最多 20 篇，队列最多 60 项；每轮后台最多处理 3 篇。已发送失败或结果未知的正文版本不自动重复请求，可手动重试。离开预览不取消独立自动任务，系统仍可停止后台执行。

政策库支持 UTF-8 TXT 和文字版 PDF，在本机检索有限段落；自动发送这些片段需单独授权。通知概述缓存与政策关联分开，政策变更可使关联失效而保留仍有效的通知概述，不自动重跑全部历史通知。图片、附件文件、校园凭据和用户画像不加入 AI 请求。

详细限制及评测方法见 [AI 摘要说明](docs/AI_SUMMARY.md)，本轮实际验证范围见 [验证记录](docs/VALIDATION.md)。

## 构建与工程

需要 JDK 17、Android SDK 36 / Build Tools 36.0.0；完整 App 还需自行取得有权使用的 `SangforSDK.aar`。仓库不提供或自动下载该专有二进制。

```sh
# 使用合成数据的核心检查，不编译厂商 SDK
./gradlew :checks:verify

# Android 主机测试与调试构建
./gradlew :app:testDebugUnitTest :app:assembleDebug :app:lintDebug -PsangforSdk=/absolute/path/SangforSDK.aar
```

Windows 使用 `gradlew.bat`。构建、签名与平台限制见 [BUILDING.md](BUILDING.md)。

| 模块 | 职责 |
| --- | --- |
| `campus-config` | 北邮公开预设、网址校验、站点范围 |
| `campus-auth` | 延迟初始化的官方 SDK 适配、VPN 认证及隧道状态 |
| `app` | 原生登录、直连 / VPN 选路、阅读、推荐、提醒、AI、政策与媒体 |
| `campus-extension` | SQLite 通知缓存、稳定身份、阅读状态、标签和摘要 |
| `campus-portal` | 门户列表、详情、附件和分页解析 |
| `checks` | 合成数据的 JVM 回归检查 |

数据流和隔离边界见 [架构说明](docs/ARCHITECTURE.md)。

## 公开边界与贡献

本版有意公开北邮产品名称和服务域名，首次使用不再要求配置学校。源码与 APK 不嵌入个人账号、密码、Cookie、动态码、API Key、真实通知样本、签名私钥或设备转储。厂商 SDK、第三方依赖及校园内容不属于本项目 MIT 授权范围，详见 [第三方说明](THIRD_PARTY_NOTICES.md)。

有效的既有北邮配置沿用原站点范围，直连和 VPN 共用同一门户账号的数据；切换账号继续隔离缓存、画像、密钥与会话。原来的通用配置解析代码保留给开发回归，不再作为产品入口。
